Public collaboration hub for the Children First Digital Well-Being Project and the surrounding My Buddy mobile safety experience.

Our purpose

Children First brings parents, caregivers, educators, youth advocates, safety professionals, researchers, developers, community organizations, and responsible technology partners together around one goal:

Use technology to protect children, strengthen digital well-being, and help young people navigate connected life more safely.

My Buddy is envisioned as a child-protective mobile experience that supports age-appropriate assistance, safer digital choices, trusted-adult involvement, and responsible use of artificial intelligence.

What belongs in this repository

This public repository is for:

* Community discussion and public education
* Child-safety and digital well-being research
* Public feature proposals and use cases
* Non-confidential interface concepts
* Accessibility and age-appropriate design feedback
* Partnership and pilot-program interest
* Public documentation and community resources

What does not belong here

Do not post:

* A child’s name, location, school, contact information, images, account details, or private communications
* Reports that identify a child or alleged offender
* Medical, mental-health, legal, or educational records
* Passwords, API keys, access tokens, internal URLs, or security details
* Exploit instructions or sensitive vulnerability details
* Proprietary source code, unpublished architecture, trade secrets, patent-sensitive material, or confidential partner information

See Public/Private IP Boundary before contributing.

Public access is governed by the Children First / My Buddy Public Repository License, Community Participation Terms, Privacy and Child Safety Policy, and Trademark and Brand Policy.

Technical contributions must also follow the Public Technical Boundary. The Protected Intelligence and Memory Layer is treated as a black box: public materials describe authorized behavior and integration requirements, not internal processing.

Ways to participate

1. Read the Community Code of Conduct.
2. Review the Contribution Guide.
3. Open an issue using the correct template.
4. Join public discussions without sharing personal information about a child.
5. Propose research, resources, pilot programs, or non-confidential improvements.
